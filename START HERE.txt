CHAMPIONS LEAGUE DRAFT TOOL
===========================

JUST USE IT (no install):
  Open webapp/index.html

UPDATE THE RANKINGS (needs Python 3):
  1. pip install pandas openpyxl PyYAML
  2. Drop the new ranking file into data/sources/
  3. python -m pipeline.build
  4. Reopen webapp/index.html

DYNASTY STARTUP DRAFT (separate draft, separate everything):
  Board  webapp/dynasty-board.html   rankings, weights, filters
  Draft  webapp/dynasty.html         record picks on draft night

  Its rankings go in  data/dynasty/  -- NOT data/sources/.
  The grey chip beside each name on the Draft page is Sleeper's own rank:
  the draft runs there, so it predicts who disappears next. Putting a dynasty
  list in data/sources/ would corrupt the Champions League redraft rankings.
  Picks in one draft never affect the other.

NOTES AND BYE WEEKS:
  Notes: click the Note column on the Board, or "+ note" on any Draft row.
  They save instantly and are PER BOARD -- a note on a dynasty player is not
  visible on the redraft board, even for the same player.

  Bye weeks: filled in from FantasyPros (config/byes.yml, all 32 teams).
  To change a season, edit that file and rebuild.

GUARANTEED-STORAGE MODE (if the red storage warning appears):
  python -m http.server 8777
  then open http://localhost:8777/webapp/index.html
